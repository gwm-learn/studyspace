# 链路聚合
链路聚合是指将一组物理端口捆绑在一起作为一个逻辑接口来增加带宽的方法，又称为多端口负载均衡组。   

## 基本概念
链路聚合也称端口捆绑、端口聚集或链路聚集。链路聚合是将多个端口聚合在一起形成一个汇聚组。使用链路汇聚服务的上层实体把同一聚合内多条物理链路视为一条逻辑链路，一个汇聚组好像就是一个端口。   

1. 增加网络带宽
2. 提高网络连接的可靠性

# LACP
链路聚合控制协议是基于IEEE 802.3ad标准的用于实现链路动态汇聚的协议   

## LACP 协议细节

LACP（Link Aggregation Control Protocol）基于 IEEE 802.3ad（现并入 802.1AX），通过对端设备间交换 **LACPDU** 报文自动协商聚合组。

### LACP 报文与工作过程

1. 设备周期发送 LACPDU（默认 1s 一次，慢速模式 30s），报文中携带自身的**系统优先级+系统 MAC** 以及**端口优先级+端口号**。
2. 对端收到后计算 actor（本端）/partner（对端）的优先级组合，协商出一个**活动链路集合**。
3. 协商成功后各成员链路进入聚合状态，共享一个逻辑接口。
4. 链路故障时通过超时机制（短超时 3s / 长超时 90s）快速剔除故障成员，重新协商。

### 关键概念

| 概念 | 说明 |
|------|------|
| Actor/Partner | 本端/对端的 LACP 状态信息，报文中成对出现 |
| 系统优先级 | 决定哪一端是主控方，数值小者优先 |
| 端口优先级 | 决定成员端口的取舍，数值小者优先加入 |
| LACP 超时 | 快/慢两种模式，决定检测对端失效的速度 |
| 成员聚合数 | 一个聚合组最多通常支持 8 个活动成员 |

### LACP 与手工聚合的对比

| 对比项 | 手工聚合（静态） | LACP 动态聚合 |
|--------|------------------|----------------|
| 协商 | 无需协商，直接捆绑 | 通过 LACPDU 自动协商 |
| 对端误配检测 | 无法自动发现 | 优先级/Key 不一致可自动发现 |
| 链路故障切换 | 依赖上层协议检测 | LACP 超时机制快速切换 |
| 配置复杂度 | 低 | 需保证两端参数一致 |

### 负载分担

聚合链路流量按**哈希**分摊到各成员链路，常见哈希因子：源 MAC、目的 MAC、源 IP、目的 IP、源/目的端口，可组合配置。哈希不均时会出现某个成员拥塞而其他成员空闲，需按流量特征调整哈希因子。

## 链路聚合方式

3. 动态聚合
