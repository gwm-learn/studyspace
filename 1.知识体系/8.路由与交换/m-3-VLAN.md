# VLAN简介
虚拟局域网技术VLAN技术把用户划分成多个逻辑的网络，每个逻辑网络内的用户形成一个组。组内可以通信，组间不允许通信。   
将不同的终端分别加入不同的VLAN中，不同VLAN之间的用户无法通过二层实现通信。    
为了实现转发控制，VLAN技术在待转发的以太网帧中添加了VLAN标签。    

# VLAN帧
VLAN标签长度为32位，对应协议IEEE 802.1Q。   
VLAN标签由TPID(0x8100)和TCI两部分组成，TCI包含三个字段：PRI(优先级)、CFI(标准格式指示)、VLANID(VLAN标识)

## 802.1Q 标签字段详解

| 字段 | 长度 | 说明 |
|------|------|------|
| TPID | 16 bit | 标签协议标识，固定 0x8100，用于识别帧携带 VLAN 标签 |
| PRI（PCP） | 3 bit | 优先级，0~7，供 QoS 队列调度使用（如语音、视频优先） |
| CFI/DEI | 1 bit | 标准格式指示，以太网帧中通常为 0 |
| VID | 12 bit | VLAN ID，0~4095，其中 0 和 4095 保留，可用 1~4094 |

VLAN 标签插在**源 MAC 地址与长度/类型字段之间**，插入后以太网帧最大长度从 1518 字节变为 1522 字节。802.1Q 只支持 4094 个 VLAN，不足时用 802.1ad（QinQ，双标签）扩展，运营商常用来为多个用户叠加外层业务标签。

# VLAN基本概念
接入链路：连接用户主机和交换机的链路   
干道链路：连接交换机和交换机的链路   
接入端口：交换机上用来连接用户主机的端口   
干道端口：交换机上用来和其他交换机连接的端口   
混合端口：交换机上既可以连接用户主机又可以连接其他交换机的端口   

# VLAN端口类型

| 端口类型 | 处理带标签帧 | 处理不带标签帧 | 典型连接对象 |
|----------|--------------|----------------|--------------|
| Access（接入） | 剥离标签后转发 | 打上 PVID 后转发 | 用户主机、终端设备 |
| Trunk（干道） | 按允许列表转发 | 打上 PVID（默认 VLAN 1）转发 | 交换机互联、路由器子接口 |
| Hybrid（混合） | 按允许列表转发，可配置是否剥离 | 打上 PVID 转发 | 可同时连接主机与交换机，灵活配置 |

## Access 端口
- 端口只属于一个 VLAN，PVID 即所属 VLAN。
- 收到不带标签的帧打上 PVID，收到带标签的帧若标签不是 PVID 则丢弃。
- 发送帧时总是**剥离标签**，保证主机收到的帧是普通以太网帧。

## Trunk 端口
- 默认允许所有 VLAN 通过，可通过 `allowed vlan` 限定白名单。
- 发送帧时默认**保留标签**，对端交换机凭标签区分 VLAN。
- 本征 VLAN（native VLAN）的帧在 Trunk 上不携带标签，两端 PVID 必须一致，否则会出现 VLAN 错位。

## Hybrid 端口
- 介于 Access 与 Trunk 之间，可配置哪些 VLAN 的帧发送时剥离标签、哪些保留。
- 常用于连接既需跨 VLAN 通信又需直接接入的混合场景，如路由器、特殊终端。
