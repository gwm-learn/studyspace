# 路由
路由（Routing）就是指路由器根据网络地址（IP 地址），在复杂的网络迷宫中，为数据包寻找最佳路径并将其转发到目的地的过程   

# 路由来源
1. 链路层协议发现的路由 (又称接口路由或直连路由)
2. 静态路由
3. 动态路由协议发现的路由

# 路由协议分类
1. 路由信息协议 RIP
2. 开放式最短路径优先协议 OSPF
3. 中间系统到中间系统协议 IS-IS
4. 边界网关协议 BGP

# 路由表结构

路由器把"网络如何走"记录在路由表中，一条路由条目包含：

| 字段 | 说明 |
|------|------|
| 目的网络/掩码 | 目标网段，如 10.0.0.0/8 |
| 下一跳 | 转发该网络流量要交给的邻居地址 |
| 出接口 | 从哪个物理/逻辑接口发出 |
| 协议来源 | Direct/Static/RIP/OSPF/BGP 等 |
| 优先级（管理距离） | 同一目的多条路由时选优依据 |
| 度量值（metric） | 协议内部计算的开销，同协议内比较 |

路由器查表遵循**最长前缀匹配**：目的地址匹配多条路由时，掩码最长（最具体）的路由优先；前缀相同则比较优先级，再比度量值。

# 静态路由与动态路由

| 对比项 | 静态路由 | 动态路由 |
|--------|----------|----------|
| 配置 | 手工逐条配置 | 协议自动学习 |
| 网络变化感知 | 不感知，需人工调整 | 自动收敛 |
| 资源消耗 | 无协议开销 | 占用带宽与 CPU |
| 适用场景 | 小网络、稳定链路、默认路由 | 大型/拓扑多变的网络 |
| 安全可控 | 高，不泄露信息 | 需认证防伪造 |

静态路由适合做默认路由和专线出口，动态路由适合内部网络规模大、链路频繁变化的场景。两者常混合使用：内网跑 OSPF，出口用静态默认路由指向运营商。

# 动态路由协议

## RIP（路由信息协议）

- **距离矢量**协议，基于 UDP 520 端口，以**跳数**为度量（最大 15 跳）。
- 每 30s 周期广播完整路由表，收敛慢且占用带宽，容易产生路由环路（靠水平分割、毒性逆转缓解）。
- 简单易配，只适合小型网络，现基本被 OSPF 取代。

## OSPF（开放最短路径优先）

- **链路状态**协议，基于 IP 协议号 89，以**带宽计算的开销（cost）**为度量。
- 邻居通过 Hello 报文建立邻接关系，全网洪泛链路状态通告（LSA），每台路由器用 **SPF（Dijkstra）算法**计算最短路径树。
- 支持区域（area）划分，骨干区 area 0 连接其他区域，适合大型企业网。
- 收敛快、无环路、支持等价多路径（ECMP），是内网路由的主流协议。

## IS-IS

- 同样基于链路状态，起源于 OSI 网络，现常用于**运营商骨干网**。
- 与 OSPF 功能类似，但使用 CLNS 地址体系，分层结构（L1/L2）天然适合大规模组网。

## BGP（边界网关协议）

- **路径矢量**协议，基于 TCP 179 端口，连接可靠。
- 核心是传播**可达性信息**（AS 路径、属性），不计算最优跳数，而是依据策略选路。
- 运行在**自治系统（AS）之间**（eBGP）和 AS 内部（iBGP），是互联网骨干路由的标准协议。
- 支持丰富的路由属性（AS_PATH、LOCAL_PREF、MED 等）实现灵活的流量工程。

## 动态路由选择对比

| 协议 | 类型 | 端口/协议 | 度量 | 适用范围 |
|------|------|-----------|------|----------|
| RIP | 距离矢量 | UDP 520 | 跳数 | 小型网络 |
| OSPF | 链路状态 | IP 89 | cost | 大型企业内网 |
| IS-IS | 链路状态 | CLNS | cost | 运营商骨干网 |
| BGP | 路径矢量 | TCP 179 | 路径属性 | 互联网/AS 间 |

# 路由选路总结

选路顺序可概括为：**最长前缀匹配 → 优先级（管理距离）→ 度量值 → 负载均衡**。直连路由优先级最高，其次静态，再次动态协议（OSPF 内部优先于 RIP，BGP 相对较低，可按需调整）。
