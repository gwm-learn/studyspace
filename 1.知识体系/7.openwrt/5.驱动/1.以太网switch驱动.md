# OpenWrt 以太网 Switch 驱动

## 一、概述

家用路由器的多个 LAN 口通常不是独立的网卡，而是由一颗交换机芯片（Switch）扩展出来的。OpenWrt 需要相应的驱动来管理这些端口与 VLAN，历史上先后出现两套框架：**swconfig** 与 **DSA**。

## 二、swconfig（传统框架）

### 2.1 特点
- 将整颗交换机芯片抽象为单一设备（如 `switch0`），端口不是独立的 Linux 网络接口。
- 通过 `swconfig` 工具配置端口属性、VLAN 表、PVID 等，配置保存在驱动内部寄存器中。
- 与 CPU 之间通常只有一条上行链路，所有端口的流量都经过该链路上送到内核。

### 2.2 常用命令
```bash
swconfig list                 # 列出交换机设备
swconfig dev switch0 show     # 查看当前配置
swconfig dev switch0 set port 4 pvid 2   # 临时设置端口 PVID
```

## 三、DSA（Distributed Switch Architecture）

### 3.1 设计理念
DSA 是 Linux 内核原生的交换机框架，将每个交换端口抽象为独立的网络接口（如 `lan1`、`lan2`），直接使用标准网络工具管理。

### 3.2 swconfig 与 DSA 对比

| 对比项 | swconfig | DSA |
|--------|----------|-----|
| 端口模型 | 整个 switch 一个设备 | 每个端口一个接口 |
| 配置工具 | swconfig | ip / bridge / 8021q |
| VLAN 配置 | switch_vlan 节 | bridge vlan 过滤 |
| 内核归属 | OpenWrt 私有补丁 | 上游 mainline 支持 |
| 发展趋势 | 逐步淘汰 | 新设备默认采用 |

### 3.3 如何判断设备使用哪套框架
```bash
ip link show
```
- 看到 `eth0`、`lan1`、`lan2` 等独立端口接口，且 `swconfig list` 为空，则为 DSA。
- 看到 `eth0`、`eth0.1`、`eth0.2` 且存在 `switch0` 设备，则为 swconfig。

## 四、常见 Switch 芯片

| 芯片 | 厂商 | 典型平台 | 框架 |
|------|------|----------|------|
| AR8327 | Qualcomm/Atheros | QCA9531、AR9344 | swconfig |
| MT7530 | MediaTek | MT7621、MT7986 | DSA |
| RTL8367 | Realtek | 部分 7620 方案/瑞昱平台 | swconfig |

### 4.1 AR8327
八口千兆交换芯片，常见于早期高通方案。通过 MDIO/MDC 或 SGMII 连接 CPU，OpenWrt 使用 `ar8327` 驱动，支持硬件 VLAN 与端口镜像。

### 4.2 MT7530
联发科主流交换芯片，接口丰富（支持 SGMII、HSGMII），OpenWrt 新版本（21.02+）默认以 DSA 方式驱动，端口直接映射为 `lan1`~`lan4`、`wan`。

### 4.3 RTL8367
瑞昱十口芯片，常用于中低端方案。驱动支持相对分散，部分依赖厂商补丁，配置仍以 swconfig 为主。

## 五、VLAN 配置

### 5.1 swconfig 方式
```uci
config switch_vlan
    option device 'switch0'
    option vlan '1'
    option ports '0 1 2 3 6t'

config switch_vlan
    option device 'switch0'
    option vlan '2'
    option ports '4 6t'
```

### 5.2 DSA 方式
DSA 使用内核标准的 8021q 与 bridge vlan，端口本身就是接口，配置在 `config device` 与 `config interface` 中：

```uci
config device
    option name 'br-lan'
    option type 'bridge'
    list ports 'lan1'
    list ports 'lan2'

config bridge-vlan
    option device 'br-lan'
    option vlan '10'
    list ports 'lan1:t'
```

## 六、调试与排查

- 查看端口状态：`ip link show`、`ethtool lan1`。
- 查看 VLAN 过滤表：`bridge vlan show`。
- 驱动日志：`dmesg | grep -i -E 'dsa|ar8327|mt7530|rtl8367'`。
- 端口不亮：检查芯片供电、MDIO 枚举是否成功，`swconfig list` 或 `ls /sys/class/net` 确认是否识别。

## 七、总结

新设备优先使用 DSA，配置更贴近标准 Linux 网络模型；老平台仍需掌握 swconfig 的 switch_vlan 写法。理解所选芯片的框架归属，是 VLAN 与多口配置排障的前提。
