# 静态IP（Static IP）配置

## 概述
静态IP（Static IP）是指为网络接口手动分配固定的IP地址、子网掩码、网关和DNS服务器，而非通过DHCP动态获取。在OpenWrt中，WAN接口配置为静态IP模式适用于以下场景：
- 运营商提供了固定的公网IP地址
- 企业内网中有预分配的IP地址段
- 需要稳定、可预测的网络连接，避免DHCP租期变化带来的中断
- 作为网关或服务器需要固定IP以便其他设备访问

静态IP配置的核心是修改WAN接口的`proto`为`static`，并填写相应的地址参数。

## 配置方法

### 1. 通过LUCI网页界面配置
1. 登录OpenWrt的LUCI管理界面（通常为 `http://192.168.1.1`）
2. 导航到 **网络** → **接口**，点击WAN接口对应的 **编辑** 按钮
3. 在 **协议** 下拉菜单中选择 **静态地址**
4. 填写以下字段：
   - **IPv4地址**：WAN接口的固定IP地址（如 `192.168.1.100`）
   - **IPv4子网掩码**：对应的子网掩码（如 `255.255.255.0`）
   - **IPv4网关**：上游网关地址（如 `192.168.1.1`）
   - **使用自定义的DNS服务器**：可填写一个或多个DNS服务器地址（如 `114.114.114.114`、`8.8.8.8`）
5. 点击 **保存并应用**，等待配置生效。

### 2. 通过UCI命令行配置
以下是一组完整的UCI命令，可将WAN接口改为静态IP模式：

```bash
# 1. 修改WAN接口协议为static
uci set network.wan.proto='static'

# 2. 设置IP地址、子网掩码、网关
uci set network.wan.ipaddr='192.168.1.100'
uci set network.wan.netmask='255.255.255.0'
uci set network.wan.gateway='192.168.1.1'

# 3. 设置DNS服务器（可添加多个）
uci set network.wan.dns='114.114.114.114'
uci add_list network.wan.dns='8.8.8.8'

# 4. 提交修改并重新加载网络配置
uci commit network
uci reload network
```

> **注意**：实际IP地址、掩码、网关和DNS需根据实际网络环境调整。

## 配置文件详解
静态IP的配置保存在 `/etc/config/network` 中，对应的WAN接口段落如下：

```uci
config interface 'wan'
        option proto 'static'
        option ipaddr '192.168.1.100'
        option netmask '255.255.255.0'
        option gateway '192.168.1.1'
        list dns '114.114.114.114'
        list dns '8.8.8.8'
```

各选项说明：
- `proto`：协议类型，静态IP固定为 `static`
- `ipaddr`：IPv4地址
- `netmask`：子网掩码
- `gateway`：默认网关地址
- `dns`：DNS服务器地址，可配置多个（使用 `list`）

## 路由与DNS
### 静态路由
若网络中存在多个网段，可能需要添加静态路由。可通过UCI添加：

```bash
uci add network route
uci set network.@route[-1].interface='wan'
uci set network.@route[-1].target='10.0.0.0/8'
uci set network.@route[-1].gateway='192.168.1.254'
uci commit network
```

### DNS配置
除了在WAN接口中设置DNS，还可以在 `/etc/config/dhcp` 中配置系统级DNS转发。静态IP模式下，通常不需要额外的DHCP客户端，DNS解析直接使用配置的DNS服务器。

## 防火墙与区域
OpenWrt默认将WAN接口归属到 `wan` 防火墙区域，该区域默认策略为 **拒绝入站、允许出站**。静态IP配置不会改变防火墙规则，但需注意：
- 若需要从外网访问OpenWrt设备（如SSH、Web管理），需在 **网络** → **防火墙** 中开放相应端口。
- 若WAN接口所在网络有特殊安全策略（如MAC过滤、IP白名单），需确保OpenWrt的MAC地址和IP地址被允许。

## 故障排除
### 1. 无法上网
- 检查IP地址、子网掩码、网关是否与上游网络匹配。
- 使用 `ping` 测试网关是否可达：`ping 192.168.1.1`
- 检查DNS解析：`nslookup openwrt.org 114.114.114.114`

### 2. 路由问题
- 查看路由表：`ip route show`
- 确认默认路由指向正确的网关。

### 3. DNS解析失败
- 检查 `/etc/resolv.conf` 中是否有正确的DNS服务器。
- 尝试使用 `dig` 或 `nslookup` 直接向配置的DNS服务器发起查询。

### 4. 配置未生效
- 确认已执行 `uci commit network` 和 `uci reload network`（或 `/etc/init.d/network restart`）。
- 查看系统日志：`logread | grep network`

## 总结
静态IP是OpenWrt WAN接口中最简单、最稳定的连接方式之一。通过正确的地址、网关和DNS配置，可以确保设备在固定IP环境中可靠工作。配置时务必与网络管理员或运营商确认地址参数，避免冲突。
