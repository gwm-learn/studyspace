# OpenWrt 作为 DHCP 服务器（dnsmasq）

## 一、概述
OpenWrt 的 DHCP 服务器由 **dnsmasq** 提供，与 DNS 服务共用同一进程。LAN 侧接口启用 DHCP 后，局域网设备通过四步握手（Discover → Offer → Request → Ack）动态获取 IP、网关、DNS。配置保存在 `/etc/config/dhcp`，由 `/etc/init.d/dnsmasq` 启动加载。协议细节见 [DHCP 协议](./../../../../../3.协议应用/4.dhcp/DHCP.md)。

## 二、配置文件结构
`/etc/config/dhcp` 分两部分：**dnsmasq 全局配置** + **每个接口的 dhcp 池**。

### 2.1 dnsmasq 全局段
```uci
config dnsmasq
        option domainneeded '1'
        option boguspriv '1'
        option filterwin2k '0'
        option localise_queries '1'
        option rebind_protection '1'
        option local '/lan/'
        option domain 'lan'
        option expandhosts '1'
        option nonegcache '0'
        option authoritative '1'
        option readethers '1'
        option leasefile '/tmp/dhcp.leases'
        option resolvfile '/tmp/resolv.conf.auto'
```
- `authoritative`：`1` 时对不在地址池内的请求直接回 NAK，加快设备重连
- `leasefile`：租约数据库文件，重启后保留已分配记录
- `resolvfile`：上游 DNS 来源（WAN 侧 DHCP 下发的自动文件）

### 2.2 DHCP 地址池段
```uci
config dhcp 'lan'
        option interface 'lan'
        option start '100'
        option limit '150'
        option leasetime '12h'
        option dhcpv4 'server'
        option dhcpv6 'server'
        option ra 'server'
        option ra_slaac '1'
```
- `start` / `limit`：地址池为 `192.168.1.100 ~ 192.168.1.249`（100 + 150）
- `leasetime`：租期，默认 `12h`
- `dhcpv4`：IPv4 服务开关；`dhcpv6` / `ra`：IPv6 分配与路由通告

## 三、dnsmasq 的 DHCP 功能特性
1. **租期管理**：`/tmp/dhcp.leases` 记录分配情况，续约在 50%（T1）和 87.5%（T2）触发
2. **Option 推送**：自动下发网关（option 3）、DNS（option 6）、域后缀（option 15）
3. **自定义 Option**：通过 `dhcp_option` 添加：
```uci
config dhcp 'lan'
        option interface 'lan'
        option dhcp_option '42,192.168.1.1'   # 自定义 NTP 服务器
```
4. **PXE 启动**：通过 `dhcp_boot` 选项配合 TFTP 实现网络启动

## 四、静态绑定（固定 IP）
根据 MAC 地址为指定设备分配固定 IP，避免地址变化影响服务（如打印机、NAS）。

### 4.1 UCI 配置
```uci
config host
        option name 'printer'
        option mac 'aa:bb:cc:dd:ee:ff'
        option ip '192.168.1.200'
        option leasetime 'infinite'
```
- `name`：设备名，同时写入本地 DNS（支持主机名解析）
- `mac`：设备 MAC，多个网卡用 `list mac`
- `ip`：固定分配的 IP，需在地址池范围外或与池内不冲突
- `leasetime 'infinite'`：永久租约，绑定后地址不再过期

### 4.2 绑定流程
1. 设备首次接入时 dnsmasq 会为它分配动态地址
2. 配置 `config host` 段后，该 MAC 请求时直接返回固定 IP
3. `hostapd`（WiFi）会把设备名同步到 ARP 表，便于查看在线状态

## 五、与防火墙 / netifd 的配合
- DHCP 请求报文（UDP 67/68）由 LAN 侧防火墙放行，dnsmasq 监听 `*:67`
- 接口 down 时 dnsmasq 通过 hotplug 脚本（`/etc/hotplug.d/iface/25-dnsmasq`）自动调整监听范围
- 多网段场景：每个 `config dhcp` 段对应一个接口，各自独立地址池

## 六、常见排查
| 现象 | 排查思路 |
|------|----------|
| 设备拿不到 IP | `logread \| grep dnsmasq`，确认接口 up 且地址池有效 |
| 地址与绑定冲突 | `cat /tmp/dhcp.leases` 查看已分配记录 |
| 绑定不生效 | 核对 MAC 格式（小写、冒号分隔），重启 dnsmasq |
| IPv6 不通 | 确认 `dhcpv6` / `ra` 开启，检查上游是否下发 IPv6 PD |
| 主机名解析失败 | 确认 `expandhosts '1'` 和 `local '/lan/'` 配置 |
