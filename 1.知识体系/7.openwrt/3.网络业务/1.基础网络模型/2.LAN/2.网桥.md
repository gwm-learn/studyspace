# 网桥（Bridge）配置

## 概述
**网桥**（Bridge）是一种工作在数据链路层（OSI第二层）的网络设备，用于连接两个或多个网段，并在它们之间转发帧。与路由器不同，网桥不处理IP地址，而是根据MAC地址进行转发，因此所有连接到同一网桥的接口属于**同一个广播域**。

在OpenWrt中，网桥的典型应用包括：
- **LAN网桥（br-lan）**：将多个有线LAN端口和无线Wi‑Fi接口桥接在一起，使有线与无线设备处于同一子网，可直接通信。
- **Guest网络隔离**：创建独立的网桥，将Guest WiFi与主LAN隔离开。
- **虚拟化环境**：为KVM/LXC容器提供虚拟网络桥接。

OpenWrt使用Linux内核的`bridge`模块实现网桥功能，并通过`netifd`（网络接口守护进程）管理网桥的配置与状态。

## 网桥基础知识
### 网桥 vs 路由器
| 特性 | 网桥（Bridge） | 路由器（Router） |
|------|----------------|------------------|
| 工作层级 | 数据链路层（L2） | 网络层（L3） |
| 寻址依据 | MAC地址 | IP地址 |
| 广播域 | 同一广播域 | 不同广播域 |
| 隔离能力 | 无（所有接口在同一广播域） | 有（每个接口属于不同子网） |
| 典型应用 | 扩展局域网，连接有线与无线 | 连接不同子网，实现网络间通信 |

### 网桥的关键概念
- **成员接口**：加入网桥的物理或虚拟接口（如 `eth0.1`、`wlan0`）。
- **网桥接口**：虚拟出的逻辑接口（如 `br-lan`），拥有自己的MAC地址和IP地址。
- **STP（生成树协议）**：防止网络中出现环路的协议，OpenWrt默认关闭STP。
- **转发数据库（FDB）**：网桥学习到的MAC地址与接口的映射表，用于决定帧的转发出口。

## OpenWrt中的默认网桥
全新安装的OpenWrt通常已配置一个名为 `br-lan` 的网桥，其成员包括：
- 有线LAN端口（如 `eth0.1`，对应VLAN 1）
- 无线接口（如 `wlan0`，如果已启用）

可以通过以下命令查看现有网桥信息：
```bash
# 查看网桥列表
brctl show

# 查看网桥详细信息
bridge link show
```

## 配置网桥
### 1. 通过LUCI网页界面配置
1. 登录LUCI（`http://192.168.1.1`）
2. 进入 **网络** → **接口**，点击 **LAN** 的 **编辑**
3. 在 **物理设置** 选项卡中，勾选需要桥接的接口（如 `eth0.1`、`wlan0`）
4. 确保 **创建网桥** 选项已选中（默认已选中）
5. 保存并应用，等待网络重启。

### 2. 通过UCI命令行配置
UCI配置网桥的核心是修改 `/etc/config/network` 文件。以下示例演示如何创建或修改网桥。

#### 示例1：将Wi‑Fi接口加入现有LAN网桥
默认情况下，Wi‑Fi接口可能未桥接到LAN。手动添加的步骤如下：

```bash
# 查看当前LAN接口的ifname（成员接口）
uci get network.lan.ifname
# 输出可能是 "eth0.1"

# 将wlan0添加到LAN网桥的成员列表中
uci set network.lan.ifname='eth0.1 wlan0'

# 提交并重新加载网络配置
uci commit network
uci reload network
```

#### 示例2：创建新的网桥（如Guest网络）
```bash
# 创建新接口br‑guest，类型为bridge
uci set network.guest=interface
uci set network.guest.proto='static'
uci set network.guest.ipaddr='192.168.3.1'
uci set network.guest.netmask='255.255.255.0'
uci set network.guest.type='bridge'          # 关键：指定为网桥
uci set network.guest.ifname='eth0.3 wlan1'  # 成员接口：VLAN 3和第二个Wi‑Fi接口

# 提交并生效
uci commit network
uci reload network
```

#### 示例3：调整网桥参数（STP、老化时间）
```bash
# 启用STP（防止环路，但会增加收敛时间）
uci set network.lan.stp='1'

# 设置MAC地址老化时间（秒）
uci set network.lan.ageing_time='300'

# 提交并生效
uci commit network
uci reload network
```

## 网桥配置详解
### 配置文件结构
在 `/etc/config/network` 中，网桥接口的配置段落如下：

```uci
config interface 'lan'
        option proto 'static'
        option ipaddr '192.168.1.1'
        option netmask '255.255.255.0'
        option type 'bridge'                 # 标识该接口为网桥
        option ifname 'eth0.1 wlan0'         # 成员接口列表，以空格分隔
        option stp '0'                       # 是否启用STP
        option ageing_time '300'             # MAC地址老化时间（秒）
        option igmp_snooping '0'             # IGMP侦听（可选）
```

### 关键选项说明
- `type`：必须设置为 `bridge`，表示该接口为网桥。
- `ifname`：成员接口列表，多个接口用空格分开。接口可以是物理接口（`eth0`）、VLAN接口（`eth0.1`）或虚拟接口（`wlan0`）。
- `stp`：生成树协议，`0`表示禁用（默认），`1`表示启用。在简单拓扑中可禁用，若网络存在环路则应启用。
- `ageing_time`：MAC地址在转发数据库中的存活时间，超时后条目被删除。默认300秒。
- `igmp_snooping`：IGMP侦听，可减少组播流量，默认禁用。

### 添加/移除成员接口
```bash
# 查看当前成员
uci get network.lan.ifname

# 添加新成员（例如添加eth0.2）
uci set network.lan.ifname='eth0.1 wlan0 eth0.2'

# 移除成员（例如移除wlan0）
uci set network.lan.ifname='eth0.1 eth0.2'

# 提交并生效
uci commit network
uci reload network
```

## 实际应用场景
### 场景一：有线与无线桥接（最常见的需求）
目标：让连接到Wi‑Fi的设备与有线设备处于同一子网（192.168.1.0/24），可直接互访。

**步骤**：
1. 确保LAN接口已配置为网桥（`type='bridge'`）
2. 将Wi‑Fi接口（如`wlan0`）添加到LAN的`ifname`列表中
3. 重启网络或重新加载配置

**UCI命令**：
```bash
uci set network.lan.type='bridge'
uci set network.lan.ifname='eth0.1 wlan0'
uci commit network
uci reload network
```

### 场景二：创建隔离的Guest网络
目标：创建一个独立的网桥 `br-guest`，使用不同的子网（192.168.3.0/24），并通过防火墙规则禁止其访问主LAN。

**步骤**：
1. 创建VLAN接口（如`eth0.3`）或使用独立的物理端口
2. 创建网桥接口`guest`，并绑定VLAN和Guest Wi‑Fi接口（`wlan1`）
3. 配置IP地址和DHCP服务器
4. 设置防火墙规则，限制`guest`区域到`lan`区域的转发

**UCI命令**（仅供参考，需根据实际接口调整）：
```bash
# 创建VLAN 3（假设交换机支持）
uci set network.guest_vlan=switch_vlan
uci set network.guest_vlan.device='switch0'
uci set network.guest_vlan.vlan='3'
uci set network.guest_vlan.ports='0t 3'   # 请根据实际硬件调整
uci commit network

# 创建网桥接口
uci set network.guest=interface
uci set network.guest.proto='static'
uci set network.guest.ipaddr='192.168.3.1'
uci set network.guest.netmask='255.255.255.0'
uci set network.guest.type='bridge'
uci set network.guest.ifname='eth0.3 wlan1'

# 配置DHCP
uci set dhcp.guest=dhcp
uci set dhcp.guest.interface='guest'
uci set dhcp.guest.start='100'
uci set dhcp.guest.limit='150'
uci set dhcp.guest.leasetime='12h'

# 提交所有配置
uci commit network
uci commit dhcp
uci reload network
/etc/init.d/dnsmasq restart
```

### 场景三：多网桥实现端口隔离
在某些场景下，可能需要将不同的物理端口分配到不同的网桥，实现端口间的二层隔离。例如：
- `br-lan`：绑定 `eth0.1`、`wlan0`，用于内部网络
- `br-iot`：绑定 `eth0.2`，用于物联网设备，与主LAN隔离

配置方法与创建Guest网络类似，只需为每个网桥定义独立的接口和IP子网。

## 故障排除
### 1. 网桥未创建或成员接口未加入
- 检查 `/etc/config/network` 中对应接口的 `type` 是否为 `bridge`
- 确认 `ifname` 列出的接口名称正确且存在（使用 `ip link show` 查看）
- 查看系统日志：`logread | grep netifd`

### 2. 网络环路导致广播风暴
- 若网络中出现环路，可能导致广播风暴、性能下降
- 启用STP：`uci set network.lan.stp='1'` 并 `uci reload network`
- 检查拓扑，避免物理环路

### 3. 网桥转发性能差
- 检查CPU使用率，网桥转发由CPU处理，高速流量可能导致负载升高
- 考虑使用硬件加速（如某些SoC支持硬件桥接）
- 减少不必要的成员接口，缩小广播域

### 4. 无线客户端无法与有线设备通信
- 确认无线接口已加入LAN网桥的 `ifname`
- 检查防火墙规则，确保 `lan` 区域内的转发被允许
- 使用 `tcpdump` 抓包分析：`tcpdump -i br-lan -n`

### 5. 网桥MAC地址异常
- 网桥接口的MAC地址通常取自第一个成员接口，但有时可能变化
- 可手动设置MAC地址：`uci set network.lan.macaddr='xx:xx:xx:xx:xx:xx'`

## 总结
网桥是OpenWrt网络中实现二层连接的核心组件，尤其在有线与无线融合、多接口统一管理场景中不可或缺。配置网桥时需注意：
1. **明确需求**：是扩展LAN还是创建隔离网络？
2. **正确配置**：确保 `type='bridge'` 且 `ifname` 包含所有需要桥接的接口。
3. **注意环路**：在复杂拓扑中启用STP。
4. **结合防火墙**：通过防火墙规则控制网桥间的流量访问。

掌握网桥配置后，可以灵活设计家庭、企业或实验室的网络结构，满足不同设备间的连通性与隔离性要求。
