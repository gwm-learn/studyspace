# 网段（子网）配置

## 概述
**网段**（又称子网）是指一个IP网络中具有相同网络地址的一组主机。子网划分（Subnetting）可以将一个大网络分割成多个较小的广播域，从而实现：
- **广播隔离**：减少广播流量，提升网络性能
- **安全管理**：不同子网之间可通过防火墙策略控制访问
- **地址规划**：更高效地利用IP地址空间
- **逻辑隔离**：如Guest网络、IoT设备网络、办公网络等

在OpenWrt中，常见的网段应用场景包括：
- 默认LAN子网（通常为 `192.168.1.0/24`）
- 通过VLAN划分多个子网（如 `192.168.2.0/24`、`192.168.3.0/24`）
- 创建独立的Guest网络子网
- 为不同物理接口分配不同子网

## 子网基础知识
### IP地址与子网掩码
- **IP地址**：如 `192.168.1.100`，由网络部分和主机部分组成
- **子网掩码**：如 `255.255.255.0`（或 `/24`），用于区分网络位和主机位
- **CIDR表示法**：`192.168.1.0/24` 表示前24位为网络位，后8位为主机位

### 关键地址
- **网络地址**：主机位全为0（如 `192.168.1.0`）
- **广播地址**：主机位全为1（如 `192.168.1.255`）
- **可用主机范围**：`192.168.1.1` ~ `192.168.1.254`（共254个地址）

### 常见子网划分
- `/24`：254个主机，子网掩码 `255.255.255.0`
- `/25`：126个主机，子网掩码 `255.255.255.128`
- `/26`：62个主机，子网掩码 `255.255.255.192`

## OpenWrt中的网段配置
### 1. 默认LAN子网
OpenWrt初次启动后，LAN接口通常配置为 `192.168.1.1/24`。若要修改此子网，可通过以下方法：

#### 通过LUCI修改
1. 登录LUCI（`http://192.168.1.1`）
2. 进入 **网络** → **接口**，点击 **LAN** 的 **编辑**
3. 在 **IPv4地址** 处输入新的IP地址（如 `10.0.0.1`）
4. **IPv4子网掩码** 选择对应的掩码（如 `255.255.255.0`）
5. 保存并应用，设备会重启网络，后续需使用新IP（`10.0.0.1`）访问管理界面。

#### 通过UCI命令行修改
```bash
# 修改LAN接口IP地址和子网掩码
uci set network.lan.ipaddr='10.0.0.1'
uci set network.lan.netmask='255.255.255.0'
uci commit network
uci reload network
```

### 2. 创建多个子网
在OpenWrt中可以通过以下三种方式创建额外的子网：

#### 方法一：添加新的LAN接口（推荐）
创建一个新的逻辑接口（如 `lan2`），并绑定到独立的物理端口或VLAN。

```bash
# 创建新接口
uci set network.lan2=interface
uci set network.lan2.proto='static'
uci set network.lan2.ipaddr='192.168.2.1'
uci set network.lan2.netmask='255.255.255.0'

# 绑定到物理接口（例如 eth0.2）
uci set network.lan2.ifname='eth0.2'

# 启用DHCP服务器
uci set dhcp.lan2=dhcp
uci set dhcp.lan2.interface='lan2'
uci set dhcp.lan2.start='100'
uci set dhcp.lan2.limit='150'
uci set dhcp.lan2.leasetime='12h'

# 提交并生效
uci commit network
uci commit dhcp
uci reload network
/etc/init.d/dnsmasq restart
```

#### 方法二：通过VLAN划分
若交换机支持802.1Q，可以在物理接口上创建多个VLAN标签，每个VLAN对应一个子网。

1. 在 **网络** → **交换机** 中配置VLAN
2. 为每个VLAN创建接口（如 `eth0.1`、`eth0.2`）
3. 为每个接口分配不同的IP子网

#### 方法三：使用虚拟接口（alias）
在同一物理接口上添加多个IP地址（别名），实现多个子网共享同一广播域（不推荐，因为广播仍会互通）。

```bash
uci set network.lan.ipaddr='192.168.1.1'
uci add_list network.lan.ipaddr='192.168.2.1'
uci set network.lan.netmask='255.255.255.0'
uci commit network
```

## DHCP地址池与子网
每个子网通常需要独立的DHCP服务器，以便为客户端自动分配IP地址。OpenWrt使用 `dnsmasq` 作为DHCP服务器，配置位于 `/etc/config/dhcp`。

### 为子网配置DHCP
```uci
config dhcp 'lan2'
        option interface 'lan2'
        option start '100'
        option limit '150'
        option leasetime '12h'
        option dhcpv6 'server'
        option ra 'server'
```

- `interface`：关联的接口名
- `start`：地址池起始地址（如 `100` 表示 `192.168.2.100`）
- `limit`：地址数量（如 `150` 表示可分配 `192.168.2.100` ~ `192.168.2.249`）
- `leasetime`：租期

## 子网间的路由
默认情况下，OpenWrt会为每个接口自动生成直连路由。若子网之间需要互通，必须满足：
1. **IP转发已启用**（OpenWrt默认开启）
2. **存在到达对方子网的路由**（如果子网都直接连接在OpenWrt上，则路由自动存在）
3. **防火墙允许转发**

### 检查IP转发
```bash
sysctl net.ipv4.ip_forward
# 若返回 net.ipv4.ip_forward = 1 表示已开启
```

### 静态路由（用于更复杂的拓扑）
若子网不在同一设备上，需添加静态路由。例如，子网 `192.168.2.0/24` 需要通过网关 `192.168.1.254` 到达：

```bash
uci add network route
uci set network.@route[-1].interface='wan'
uci set network.@route[-1].target='192.168.2.0'
uci set network.@route[-1].netmask='255.255.255.0'
uci set network.@route[-1].gateway='192.168.1.254'
uci commit network
uci reload network
```

## 防火墙配置
OpenWrt的防火墙基于区域（zone）和转发（forwarding）策略。默认情况下，所有LAN接口（包括新创建的 `lan2`）都属于 `lan` 区域，`lan` 区域内的流量允许互相转发。

### 查看防火墙区域
```bash
uci show firewall
```

### 允许子网间通信
若子网接口未加入 `lan` 区域，需手动添加：

```bash
# 将 lan2 加入 lan 区域
uci set firewall.lan2_zone=zone
uci set firewall.lan2_zone.name='lan'
uci set firewall.lan2_zone.network='lan2'
uci set firewall.lan2_zone.input='ACCEPT'
uci set firewall.lan2_zone.output='ACCEPT'
uci set firewall.lan2_zone.forward='ACCEPT'

# 允许 lan 与 lan2 之间的转发
uci set firewall.lan_lan2_forwarding=forwarding
uci set firewall.lan_lan2_forwarding.src='lan'
uci set firewall.lan_lan2_forwarding.dest='lan2'

uci commit firewall
/etc/init.d/firewall restart
```

### 禁止子网间通信
若需要隔离子网（如Guest网络），可将新接口分配到独立的防火墙区域，并禁止与 `lan` 区域的转发。

## 实战示例：配置两个子网并互通
**场景**：在OpenWrt上创建两个子网：
- `lan`：`192.168.1.0/24`，IP `192.168.1.1`
- `lan2`：`192.168.2.0/24`，IP `192.168.2.1`

**目标**：两个子网内的设备可以互相访问。

**步骤**：
1. 创建 `lan2` 接口并设置IP
2. 为 `lan2` 配置DHCP
3. 将 `lan2` 加入防火墙 `lan` 区域（或确保已在同一区域）
4. 验证连通性

**UCI命令汇总**：
```bash
# 1. 创建接口
uci set network.lan2=interface
uci set network.lan2.proto='static'
uci set network.lan2.ipaddr='192.168.2.1'
uci set network.lan2.netmask='255.255.255.0'
uci set network.lan2.ifname='eth0.2'

# 2. 配置DHCP
uci set dhcp.lan2=dhcp
uci set dhcp.lan2.interface='lan2'
uci set dhcp.lan2.start='100'
uci set dhcp.lan2.limit='150'
uci set dhcp.lan2.leasetime='12h'

# 3. 防火墙（若未自动加入lan区域）
uci set firewall.lan2_zone=zone
uci set firewall.lan2_zone.name='lan'
uci set firewall.lan2_zone.network='lan2'
uci set firewall.lan2_zone.input='ACCEPT'
uci set firewall.lan2_zone.output='ACCEPT'
uci set firewall.lan2_zone.forward='ACCEPT'

# 4. 提交并生效
uci commit network
uci commit dhcp
uci commit firewall
uci reload network
/etc/init.d/dnsmasq restart
/etc/init.d/firewall restart
```

**验证**：
- 在 `192.168.1.0/24` 网段的设备上 ping `192.168.2.1`
- 在 `192.168.2.0/24` 网段的设备上 ping `192.168.1.1`
- 检查路由表：`ip route show`

## 故障排除
### 1. 子网内设备无法获取IP
- 检查DHCP配置是否正确，`interface` 是否与接口名一致
- 查看dnsmasq日志：`logread | grep dnsmasq`
- 确认物理链路和VLAN配置

### 2. 子网间无法通信
- 检查防火墙区域和转发规则：`uci show firewall`
- 确认IP转发已开启：`sysctl net.ipv4.ip_forward`
- 查看路由表：`ip route show`
- 使用 `tcpdump` 抓包分析：`tcpdump -i eth0.2 -n`

### 3. 防火墙阻止流量
- 临时关闭防火墙测试：`/etc/init.d/firewall stop`
- 若通信恢复，说明防火墙规则需要调整

### 4. 配置未生效
- 确认已执行 `uci commit` 和 `uci reload`
- 重启相关服务：`/etc/init.d/network restart`，`/etc/init.d/dnsmasq restart`，`/etc/init.d/firewall restart`

## 总结
在OpenWrt中配置多子网是一项常见且强大的功能，可以满足不同场景下的网络隔离与互通需求。关键步骤包括：
1. **规划子网地址**：避免地址冲突，合理选择掩码
2. **创建接口**：通过UCI或LUCI添加新接口并设置IP
3. **配置DHCP**：为每个子网提供自动地址分配
4. **调整防火墙**：确保子网间的流量符合安全策略
5. **测试连通性**：验证配置是否正确生效

掌握子网配置能力后，可以灵活构建家庭、企业或实验室网络环境。
