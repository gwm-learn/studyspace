# VLAN（虚拟局域网）

## 一、概述

### 1.1 什么是 VLAN？
VLAN（Virtual Local Area Network，虚拟局域网）是一种将物理网络划分为多个逻辑网络的技术。每个 VLAN 是一个独立的广播域，同一 VLAN 内的设备可以相互通信，不同 VLAN 间的设备在二层上隔离，必须通过路由器或三层交换机才能通信。

### 1.2 VLAN 的优势
- **广播隔离**：缩小广播域，减少不必要的广播流量，提升网络性能。
- **安全性**：不同 VLAN 间的设备无法直接访问，增强网络安全性。
- **灵活性**：逻辑划分不受物理位置限制，便于网络管理与重构。
- **资源优化**：可根据部门、功能或应用划分 VLAN，实现资源精细化管控。

### 1.3 在 OpenWrt 中的应用
OpenWrt 利用 VLAN 实现以下典型场景：
- **LAN/VLAN 划分**：将单个物理接口划分为多个逻辑接口，每个 VLAN 对应一个子网（如 `eth0.1`、`eth0.2`）。
- **Guest 网络隔离**：创建独立的 VLAN 用于访客网络，与主 LAN 隔离。
- **多 SSID 对应不同 VLAN**：为每个无线 SSID 分配不同的 VLAN，实现无线用户分组。
- **WAN 连接**：某些 ISP 要求使用 VLAN tagging（如 PPPoE over VLAN）。

### 1.4 VLAN 相关标准
- **IEEE 802.1Q**：定义 VLAN 标签格式与交换行为的国际标准。
- **VLAN ID 范围**：1‑4094（0 和 4095 保留）。
- **标签格式**：在以太网帧头插入 4 字节的 802.1Q 标签，包含 TPID（0x8100）和 TCI（含 VLAN ID、优先级等）。

## 二、VLAN 技术基础

### 2.1 VLAN 标签（Tagging）
- **有标签帧（Tagged）**：帧头携带 802.1Q 标签，标识所属 VLAN。
- **无标签帧（Untagged）**：普通以太网帧，不携带 VLAN 标签。

### 2.2 端口类型
| 端口类型 | 接收处理 | 发送处理 | 典型应用 |
|----------|----------|----------|----------|
| **Access 端口** | 接收无标签帧，将其划分到端口的 PVID 所属 VLAN | 发送时剥离标签，转为无标签帧 | 连接终端设备（PC、手机） |
| **Trunk 端口** | 接收有标签帧，根据标签中的 VLAN ID 区分；接收无标签帧则划分到 PVID 所属 VLAN | 发送有标签帧（除 PVID 外），PVID 对应的 VLAN 帧以无标签形式发送 | 交换机间互联，承载多个 VLAN |
| **Hybrid 端口** | 可同时接收有标签和无标签帧，配置灵活 | 可配置某些 VLAN 发送时有标签，某些无标签 | 特殊场景，如连接服务器或支持 VLAN 的终端 |

### 2.3 PVID（Port VLAN ID）
每个端口都有一个 PVID，用于处理接收到的无标签帧。默认情况下，PVID 为 1（即 VLAN 1）。

### 2.4 VLAN 间通信
二层隔离的 VLAN 之间需要通过三层设备（路由器、三层交换机）才能通信。在 OpenWrt 中，可通过创建多个 VLAN 接口（如 `eth0.1`、`eth0.2`）并为其配置 IP 地址，然后启用 IP 转发来实现 VLAN 间路由。

## 三、Linux 内核 VLAN 支持

### 3.1 内核模块
Linux 内核通过 `8021q` 模块提供 VLAN 功能。该模块允许在物理接口上创建虚拟 VLAN 接口（如 `eth0.10`），每个 VLAN 接口对应一个 VLAN ID。

加载模块：
```bash
modprobe 8021q
```

### 3.2 软件 VLAN 接口
软件 VLAN 接口完全由 CPU 处理标签的添加与剥离，性能较低，但灵活性高。适用于不支持硬件 VLAN 的接口（如无线接口、USB 网卡）或需要复杂标签操作的场景。

创建软件 VLAN 接口：
```bash
# 使用 ip 命令
ip link add link eth0 name eth0.10 type vlan id 10

# 使用 vconfig（旧版工具）
vconfig add eth0 10
```

### 3.3 内核参数
可通过 `/sys/class/net/<iface>/` 下的文件查看或调整 VLAN 相关参数，如 `iflink`、`vid` 等。

## 四、OpenWrt VLAN 配置

OpenWrt 支持两种 VLAN 配置方式：
1. **硬件 VLAN（交换机 VLAN）**：通过交换机芯片的硬件转发，性能高，配置在 `switch` 节中。
2. **软件 VLAN（设备 VLAN）**：通过内核 `8021q` 模块实现，配置在 `device` 节中。

### 4.1 硬件 VLAN 配置（switch）
硬件 VLAN 配置针对内置交换机芯片的设备（如 MT7620、IPQ4019）。配置文件为 `/etc/config/network`，使用 `config switch_vlan` 节定义 VLAN。

#### 4.1.1 交换机基本概念
- **交换机设备**：通常为 `switch0`（单交换机）或 `switch0`、`switch1`（多交换机）。
- **端口编号**：交换机物理端口编号，如 `0`、`1`、`2`……常与外部接口对应（需查阅硬件手册）。
- **CPU 端口**：连接 CPU 的内部端口，通常标记为 `6` 或 `5`（依芯片而定）。
- **标签端口**：在 `ports` 列表中用 `t` 表示，如 `0t` 表示端口 0 为标签端口（Trunk）。

#### 4.1.2 switch_vlan 配置示例
```uci
config switch
    option name 'switch0'
    option reset '1'
    option enable_vlan '1'

config switch_vlan
    option device 'switch0'
    option vlan '1'
    option ports '0 1 2 3 6t'

config switch_vlan
    option device 'switch0'
    option vlan '2'
    option ports '4 6t'
```

上述配置定义了两个 VLAN：
- **VLAN 1**：端口 0、1、2、3 为 Access 端口（无标签），CPU 端口 6 为 Trunk 端口（标签）。
- **VLAN 2**：端口 4 为 Access 端口，CPU 端口 6 为 Trunk 端口。

#### 4.1.3 端口标记规则
- **无标记端口**：仅列出端口号（如 `0`），表示该端口属于该 VLAN，且发送帧时剥离标签（Access）。
- **标记端口**：端口号后加 `t`（如 `6t`），表示该端口属于该 VLAN，且发送帧时保留标签（Trunk）。
- **排除端口**：不列出则表示不属于该 VLAN。

#### 4.1.4 查看交换机 VLAN 状态
```bash
swconfig dev switch0 show
```

### 4.2 软件 VLAN 配置（device）
当硬件不支持 VLAN 或需要更灵活的标签操作时，可使用软件 VLAN。配置在 `config device` 节中，类型为 `vlan`。

```uci
config device
    option name 'eth0.10'
    option type 'vlan'
    option ifname 'eth0'
    option vid '10'
```

此配置会创建一个名为 `eth0.10` 的 VLAN 设备，绑定到物理接口 `eth0`，VLAN ID 为 10。

### 4.3 接口绑定 VLAN
创建 VLAN 设备后，可在 `config interface` 节中将其作为普通接口使用：

```uci
config interface 'vlan10'
    option device 'eth0.10'
    option proto 'static'
    option ipaddr '192.168.10.1'
    option netmask '255.255.255.0'
```

### 4.4 混合配置示例（硬件 VLAN + 软件 VLAN）
以下配置实现：
- 硬件 VLAN 1（LAN）和 VLAN 2（WAN）通过交换机划分。
- 在 VLAN 1 上创建软件 VLAN 10（用于 Guest 网络）。

```uci
# 硬件 VLAN
config switch_vlan
    option device 'switch0'
    option vlan '1'
    option ports '0 1 2 3 6t'

config switch_vlan
    option device 'switch0'
    option vlan '2'
    option ports '4 6t'

# 软件 VLAN（基于 VLAN 1 的接口 eth0.1）
config device
    option name 'eth0.10'
    option type 'vlan'
    option ifname 'eth0.1'
    option vid '10'

# 接口配置
config interface 'lan'
    option device 'eth0.1'
    option proto 'static'
    option ipaddr '192.168.1.1'
    option netmask '255.255.255.0'

config interface 'guest'
    option device 'eth0.10'
    option proto 'static'
    option ipaddr '192.168.10.1'
    option netmask '255.255.255.0'
```

## 五、交换机配置（swconfig 与 DSA）

### 5.1 swconfig（传统交换机配置）
OpenWrt 传统交换机驱动使用 `swconfig` 工具进行配置。上文示例即为 swconfig 风格。该方式适用于大多数基于 `switch` 驱动的设备。

常用命令：
```bash
# 查看交换机信息
swconfig list

# 查看具体交换机配置
swconfig dev switch0 show

# 临时修改端口 VLAN 成员（不保存）
swconfig dev switch0 set port 0 pvid 10
```

### 5.2 DSA（Distributed Switch Architecture）
DSA 是 Linux 内核新的交换机框架，将每个交换机端口抽象为独立的网络接口。OpenWrt 在新设备（如 MT7622、IPQ807x）上逐步采用 DSA。

DSA 特点：
- 每个物理端口对应一个 Linux 网络接口（如 `lan1`、`lan2`）。
- VLAN 配置通过 `bridge vlan` 命令管理，而非 `switch_vlan`。
- 配置更灵活，支持更复杂的 VLAN 过滤。

DSA 配置示例（UCI）：
```uci
config device
    option name 'lan1'
    option type '8021q'
    option ifname 'eth0'
    option vid '1'

config device
    option name 'lan2'
    option type '8021q'
    option ifname 'eth0'
    option vid '2'
```

### 5.3 如何判断设备使用 swconfig 还是 DSA？
查看网络接口列表：
```bash
ip link show
```
- 若看到 `eth0`、`eth1` 等且无 `switch` 接口，可能是 DSA。
- 若看到 `eth0`、`eth0.1`、`eth0.2` 等，且存在 `switch0` 设备，则为 swconfig。

## 六、软件 VLAN 配置命令

### 6.1 使用 ip 命令
```bash
# 创建 VLAN 接口
ip link add link eth0 name eth0.20 type vlan id 20

# 删除 VLAN 接口
ip link del eth0.20

# 查看 VLAN 接口信息
ip -d link show eth0.20

# 启用/禁用 VLAN 接口
ip link set eth0.20 up
ip link set eth0.20 down
```

### 6.2 使用 vconfig（已废弃）
```bash
# 创建 VLAN 接口
vconfig add eth0 30

# 设置 VLAN 接口 flags
vconfig set_flag eth0.30 1 1

# 删除 VLAN 接口
vconfig rem eth0.30
```

### 6.3 持久化配置
上述命令创建的 VLAN 接口在重启后会消失。若需持久化，必须将其写入 `/etc/config/network`。

## 七、VLAN 与桥接

### 7.1 VLAN-aware 桥接
Linux 桥接支持 VLAN 过滤，即允许桥接在不同端口上根据 VLAN ID 进行转发。这称为 VLAN-aware 桥接。

配置示例（使用 `bridge` 命令）：
```bash
# 创建桥接
ip link add name br-vlan type bridge vlan_filtering 1

# 将端口加入桥接
ip link set dev eth0 master br-vlan
ip link set dev eth1 master br-vlan

# 配置端口 VLAN 成员
bridge vlan add vid 10 dev eth0
bridge vlan add vid 20 dev eth1

# 设置端口 PVID
bridge vlan add vid 10 dev eth0 pvid untagged
```

### 7.2 OpenWrt 中的 VLAN-aware 桥接
OpenWrt 可通过 `bridge` 命令手动配置，也可在 UCI 中结合 `device` 类型为 `bridge` 和 `switch_vlan` 实现。

UCI 配置示例：
```uci
config device
    option name 'br-vlan'
    option type 'bridge'
    list ports 'eth0'
    list ports 'eth1'

config switch_vlan
    option device 'switch0'
    option vlan '10'
    option ports '0 6t'

config switch_vlan
    option device 'switch0'
    option vlan '20'
    option ports '1 6t'
```

### 7.3 VLAN 与无线桥接
无线接口（如 `wlan0`）可通过 `iw` 命令关联到 VLAN。常见场景：多个 SSID 各自对应一个 VLAN。

配置示例（`/etc/config/wireless`）：
```uci
config wifi-iface
    option device 'radio0'
    option mode 'ap'
    option ssid 'Guest'
    option network 'guest'
    option ifname 'wlan0'
    option isolate '1'
    option vid '10'   # 某些驱动支持直接设置 VLAN ID
```

若无线驱动不支持 VLAN tagging，可创建软件 VLAN 接口并桥接：
```uci
config device
    option name 'wlan0.10'
    option type 'vlan'
    option ifname 'wlan0'
    option vid '10'

config interface 'guest'
    option device 'br-guest'
    option proto 'static'
    option ipaddr '192.168.10.1'
    option netmask '255.255.255.0'
    option type 'bridge'
    option ifname 'wlan0.10 eth0.10'
```

## 八、VLAN 间路由

### 8.1 三层交换机概念
VLAN 间路由需要三层设备。在 OpenWrt 中，可通过为每个 VLAN 接口配置 IP 地址，并启用 IP 转发来实现。

### 8.2 配置步骤
1. 为每个 VLAN 创建接口并配置 IP 地址（如 `eth0.1`、`eth0.2`）。
2. 启用 IP 转发：`sysctl -w net.ipv4.ip_forward=1`。
3. 配置防火墙，允许 VLAN 间流量转发。

### 8.3 示例：VLAN 10 与 VLAN 20 互通
```uci
# VLAN 10 接口
config interface 'vlan10'
    option device 'eth0.10'
    option proto 'static'
    option ipaddr '192.168.10.1'
    option netmask '255.255.255.0'

# VLAN 20 接口
config interface 'vlan20'
    option device 'eth0.20'
    option proto 'static'
    option ipaddr '192.168.20.1'
    option netmask '255.255.255.0'
```

防火墙规则需允许 `vlan10` 与 `vlan20` 区域间的转发。

### 8.4 使用 DHCP 为不同 VLAN 分配 IP
dnsmasq 可为每个 VLAN 接口独立提供 DHCP 服务：
```uci
config dhcp 'vlan10'
    option interface 'vlan10'
    option start '100'
    option limit '150'
    option leasetime '12h'

config dhcp 'vlan20'
    option interface 'vlan20'
    option start '100'
    option limit '150'
    option leasetime '12h'
```

## 九、实际应用场景

### 9.1 场景一：家庭网络划分
- **VLAN 1（主 LAN）**：192.168.1.0/24，用于家庭成员设备。
- **VLAN 10（Guest）**：192.168.10.0/24，用于访客，限制访问内网。
- **VLAN 20（IoT）**：192.168.20.0/24，用于智能家居设备，仅允许访问互联网。

### 9.2 场景二：小型企业网络
- **VLAN 100（办公）**：192.168.100.0/24，员工电脑。
- **VLAN 200（服务器）**：192.168.200.0/24，内部服务器。
- **VLAN 300（监控）**：192.168.300.0/24，摄像头 NVR。
- **VLAN 400（Wi‑Fi）**：192.168.400.0/24，无线用户。

### 9.3 场景三：多 SSID 对应不同 VLAN
- **SSID "Office"** → VLAN 10（办公）
- **SSID "Guest"** → VLAN 20（访客）
- **SSID "IoT"** → VLAN 30（物联网）

### 9.4 场景四：WAN VLAN（ISP 要求）
某些 ISP 提供 PPPoE 服务并要求客户在 WAN 口打上特定 VLAN 标签（如 VLAN 35）。配置示例：
```uci
config device
    option name 'eth1.35'
    option type 'vlan'
    option ifname 'eth1'
    option vid '35'

config interface 'wan'
    option device 'eth1.35'
    option proto 'pppoe'
    option username 'user@isp'
    option password 'password'
```

## 十、故障排除

### 10.1 常见问题

#### VLAN 接口未创建
- 检查 `8021q` 模块是否加载：`lsmod | grep 8021q`。
- 查看系统日志：`logread | grep vlan`。
- 确认物理接口存在且 UP：`ip link show eth0`。

#### VLAN 间无法通信
- 检查 VLAN 接口 IP 配置是否正确。
- 确认 IP 转发已启用：`sysctl net.ipv4.ip_forward`。
- 检查防火墙规则是否允许转发。

#### 交换机 VLAN 不生效
- 确认交换机配置正确：`swconfig dev switch0 show`。
- 检查端口成员是否正确，CPU 端口是否标记为 `t`。
- 确认硬件支持 VLAN，且驱动已加载。

#### 无线 VLAN 无法工作
- 确认无线驱动支持 VLAN tagging。
- 检查 `ifname` 是否正确绑定到 VLAN 接口。
- 查看无线客户端是否获取到正确 VLAN 的 IP。

### 10.2 调试命令
```bash
# 查看 VLAN 接口
ip -d link show type vlan

# 查看交换机 VLAN 表
swconfig dev switch0 show

# 查看桥接 VLAN 过滤信息
bridge vlan show

# 抓包分析 VLAN 标签
tcpdump -i eth0 -n -e vlan

# 查看内核日志
dmesg | grep -i vlan
```

### 10.3 性能问题
- 软件 VLAN 会消耗 CPU 资源，在高流量场景下可能成为瓶颈。
- 考虑使用硬件 VLAN（交换机）以提升性能。
- 避免在单个物理接口上创建过多 VLAN 接口。

## 十一、面试常见问题

### 11.1 基础概念
1. **什么是 VLAN？它的主要作用是什么？**
   > VLAN 是虚拟局域网，用于在二层隔离广播域，提升网络安全性、灵活性和性能。

2. **Access 端口和 Trunk 端口有什么区别？**
   > Access 端口用于连接终端设备，收发无标签帧；Trunk 端口用于交换机互联，收发有标签帧（除 PVID 外）。

3. **VLAN ID 的范围是多少？哪些是保留的？**
   > 1‑4094，其中 0 和 4095 保留。

### 11.2 配置与调试
4. **如何在 OpenWrt 中配置硬件 VLAN？**
   > 在 `/etc/config/network` 中添加 `config switch_vlan` 节，指定 `device`、`vlan`、`ports`。

5. **如何创建软件 VLAN 接口？**
   > 使用 `ip link add link eth0 name eth0.10 type vlan id 10` 或通过 UCI 配置 `config device` 类型为 `vlan`。

6. **VLAN 间如何实现通信？**
   > 需要三层设备（路由器或三层交换机）为每个 VLAN 配置 IP 地址，并启用 IP 转发。

### 11.3 高级问题
7. **什么是 VLAN-aware 桥接？如何配置？**
   > VLAN-aware 桥接允许桥接根据 VLAN ID 过滤转发。可通过 `bridge vlan` 命令配置，或在 OpenWrt 中结合 `switch_vlan` 实现。

8. **DSA 与 swconfig 的区别是什么？**
   > swconfig 是传统交换机配置方式，将整个交换机作为一个设备管理；DSA 将每个交换机端口抽象为独立接口，配置更灵活，符合现代 Linux 网络架构。

9. **无线网络如何与 VLAN 结合？**
   > 可通过为每个 SSID 指定不同的 VLAN ID，或创建软件 VLAN 接口并桥接到无线接口。

10. **如何诊断 VLAN 不通的问题？**
    > 检查 VLAN 接口状态、交换机配置、防火墙规则，使用 `tcpdump` 抓包查看标签是否正确。

## 十二、总结

VLAN 是构建复杂网络的基础技术，在 OpenWrt 中通过硬件交换机和软件 VLAN 接口灵活实现。掌握 VLAN 的配置与调试，对于 CPE 路由器开发人员至关重要。

### 12.1 最佳实践
1. **规划先行**：根据业务需求合理划分 VLAN，避免后期调整困难。
2. **硬件优先**：尽量使用硬件 VLAN，提升性能。
3. **标签一致**：确保 Trunk 链路两端 VLAN 配置一致。
4. **安全隔离**：利用防火墙严格控制 VLAN 间访问。
5. **文档记录**：记录每个 VLAN 的 ID、用途、IP 子网，便于维护。

### 12.2 学习建议
- 阅读 IEEE 802.1Q 标准，理解 VLAN 标签格式与交换原理。
- 动手实验：在 OpenWrt 设备上创建多个 VLAN，测试隔离与互通。
