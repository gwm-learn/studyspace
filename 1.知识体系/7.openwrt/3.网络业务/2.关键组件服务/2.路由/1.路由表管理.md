# OpenWrt 路由表管理
## 一、Linux 路由表基础

Linux 支持多张路由表，每张表由编号与名称标识：
- **local（255）**：本机地址与广播路由，内核自动维护。
- **main（254）**：主路由表，普通 `ip route` 默认操作的表。
- **default（253）**：默认路由表，通常为空。
- **自定义表（1-252）**：供策略路由使用，如 `100`、`200`。

编号与名称的映射定义在 `/etc/iproute2/rt_tables`，可自行添加别名。

### 1.1 查看路由
```bash
ip route show                # 默认查看 main 表
ip route show table all      # 查看所有表
ip route show table 100      # 查看指定表
cat /proc/net/route          # 内核视角的 IPv4 路由表
```

### 1.2 路由匹配规则
路由选择遵循**最长前缀匹配**：前缀越长优先级越高；前缀相同时比较 metric，数值小的优先。匹配失败且无默认路由时，报文被丢弃。

## 二、静态路由配置

### 2.1 UCI 静态路由
在 `/etc/config/network` 中添加 `config route` 节：

```uci
config route
    option interface 'lan'
    option target '192.168.2.0'
    option netmask '255.255.255.0'
    option gateway '192.168.1.2'
    option metric '10'
```

重启网络生效：`/etc/init.d/network restart`。默认路由将 target 与 netmask 均设为 0.0.0.0，仅指定 gateway；IPv6 使用 `config route6` 节，无需 netmask：

```uci
config route6
    option interface 'lan'
    option target '2001:db8::/64'
    option gateway 'fe80::1'
```

## 三、ip rule 策略路由

### 3.1 基本概念
策略路由通过规则（rule）控制查询哪张路由表，支持按源地址、目的地址、入接口、fwmark 等条件分流。规则按优先级（pref）从低到高匹配，命中即终止。

### 3.2 常用命令
```bash
ip rule show                                   # 查看规则
ip rule add from 192.168.10.0/24 table 100     # 源地址分流
ip rule add fwmark 0x1 table 100               # 按 fwmark 分流
ip rule add iif br-guest table 200             # 按入接口分流
ip rule del pref 100                           # 删除规则
```

### 3.3 应用场景
- 特定网段强制走指定出口（如访客网络走 WAN2）。
- 结合 `iptables -t mangle -j MARK` 实现按应用、按目的 IP 的精细化分流。
- 多 WAN 环境下按业务类型分离链路。

## 四、多 WAN 负载均衡（mwan3）

### 4.1 简介
mwan3 是 OpenWrt 上主流的多 WAN 负载均衡与故障切换工具，基于 `ip rule` + `ip route` 实现，通过 hotplug 事件监听接口状态。安装：`opkg update && opkg install mwan3`。

### 4.2 核心配置
`/etc/config/mwan3` 包含 member（成员）、policy（策略）、rule（规则）三类配置：

```uci
config interface 'wan1'
    option enabled '1'
    option family 'ipv4'
    option reliability '1'      # 监控目标，默认 ping 网关
    option interval '5'
    option down '3'             # 连续失败次数判定下线
    option up '3'               # 连续成功次数判定上线

config policy 'balanced'
    list use_member 'wan1_m1_w3'
    list use_member 'wan2_m1_w3'
    option last_resort 'default'
```

### 4.3 常用策略与注意
- **balanced**：按成员权重分配流量，实现负载均衡；**failover**：主备模式，主链路故障时切到备链路。
- member 的 `weight` 决定分配比例；`reliability` 监控目标不通会导致误判，建议配置稳定可达的 IP。
- mwan3 会生成大量 ip rule，排障时优先检查 `/etc/config/mwan3` 中规则顺序，用 `mwan3 status` 查看状态。

## 五、常见问题排查
- 静态路由不生效：`ip route show table main` 检查路由是否下发，interface 未 UP、gateway 不可达、metric 冲突均会导致失败。
- 策略路由不匹配：`ip rule show` 确认规则优先级与 table 内容，注意规则命中即终止。
- mwan3 切换异常：`mwan3 status`、`logread | grep mwan3` 检查监控目标失联、规则被覆盖。

## 六、总结

路由表管理是 OpenWrt 数据转发的核心。理解 main 表、策略路由与 mwan3 三者关系，即可应对从简单静态路由到复杂多 WAN 场景的配置与排障。
