## 三、分阶段详细学习内容 \+ 实操任务（可直接落地）

### 阶段1：OpenWrt 基础体系筑基（3天）—— 解决：只会编译，不懂框架

**核心目标**：吃透 OpenWrt Buildroot 机制，脱离现成SDK，能自主搭建、裁剪、编译干净主线固件

**理论知识点**

- OpenWrt 架构本质：不是系统，是**嵌入式构建框架**

- feeds 机制：源码仓库分层、包管理原理、自定义feeds添加

- config 配置原理：target、subtarget、package 三级配置逻辑

- 固件打包流程：kernel \+ rootfs \+ 分区镜像合成原理

**必做实操（工程师级）**

1. 拉取 **OpenWrt 官方主线源码**，不使用任何大佬魔改源码

2. 完整编译一次 MT7981 官方固件，解决编译报错、依赖缺失问题

3. 手动增减软件包、关闭冗余驱动、自定义固件签名

4. 区分：SDK编译、完整源码编译、离线编译三种模式的适用场景

**阶段产出**：一套干净、可自主裁剪的官方OpenWrt编译环境

### 阶段2：底层启动与板级适配（7天）—— 补齐：从单片机到路由底层的核心短板

**核心目标**：精通 ARM 路由启动全流程，会改U\-Boot、改DTS、改分区，解决90%硬件启动问题（你STM32/51基础可无缝衔接）

**理论知识点**

- 路由设备完整启动链：上电 → U\-Boot → 内核设备树 → 内核加载 → rootfs启动 → procd初始化

- U\-Boot核心：环境变量、启动参数、分区定义、刷机流程、TTL调试

- DTS设备树核心：路由专属配置（网口、WiFi、SPI/NAND Flash、GPIO、LED、复位键）

- Flash双分区机制（OpenWrt A/B升级原理，商用路由器标配）

**必做实操（核心进阶）**

1. USB\-TTL全程抓启动日志，逐行看懂U\-Boot、内核启动打印

2. 手动修改DTS：自定义LED触发、修改复位键GPIO、调整Flash分区大小

3. 修改U\-Boot启动参数，自定义内核cmdline

4. 手动救砖、TFTP刷机、分区损坏修复（企业必备技能）

**阶段产出**：自主修改的板级DTS补丁、熟练掌握路由底层调试手段

### 阶段3：内核与路由网络核心（10天）—— 路由器开发**核心壁垒**

**核心目标**：吃透现代路由器两大核心：**DSA有线网络架构 \+ MT76 WiFi6无线驱动**，区别于普通应用层开发

**理论知识点**

- 新旧架构对比：废弃的swconfig（老路由）\& 主流DSA交换机架构（现商用AX路由通用）

- DSA核心：端口映射、VLAN、Trunk、硬件转发、流量隔离

- 联发科MT76无线驱动架构：mac80211、hostapd、wpa\_supplicant联动机制

- WiFi工作模式：AP/Client/中继/桥接 底层原理

- 内核网络参数：路由转发、iptables/nftables、硬件NAT原理

**必做实操**

1. 纯DTS配置实现多网口VLAN划分、端口隔离、Trunk配置（不依赖uci脚本）

2. 调试WiFi6 AP发射功率、信道、加密协议，抓取无线连接日志

3. 对比测试：软件转发 vs 硬件NAT转发性能差异

4. 独立排查：断流、丢包、WiFi掉线、VLAN不通等经典网络问题

**阶段产出**：掌握商用路由器有线\+无线底层核心，从“会用”变成“会调、会改、会排错”

### 阶段4：OpenWrt用户态全栈框架（10天）—— 打通你现有业务经验

**核心目标**：把你5年零散的路由业务经验系统化，彻底搞懂OpenWrt整套用户态运行机制，明白所有路由功能的底层调度逻辑

**理论知识点（企业开发核心）**

- **procd**：OpenWrt系统初始化、进程托管、开机自启、崩溃重启机制（路由系统核心）

- **netifd**：网络配置守护进程，所有上网、拨号、VLAN、无线配置的统一调度中心

- **uci**：配置文件体系原理、分层配置、默认配置覆盖机制

- LuCI架构：MVC逻辑、页面渲染、接口调用、前后端交互

- 路由核心业务：PPPoE拨号、DHCP、DNS、防火墙、QoS、访客网络

**必做实操**

1. 手动编写procd开机服务，实现自定义进程托管、异常重启

2. 纯命令行/uci配置完成全套网络，不使用网页后台

3. 从零编写一个简单LuCI页面，绑定uci配置，实现参数保存生效

4. 拆解现有路由业务脚本，梳理netifd调用链路

**阶段产出**：系统化掌握OpenWrt用户态框架，所有零散业务经验全部串联成体系

## 四、关键避坑指南（针对工程师自学）

1\. **坚决不玩魔改固件**：全程主线官方源码，学的是标准技术，不是玩家偏方，完全适配工作场景

2\. **不跳过底层直接学业务**：你最大的问题就是上层熟、底层空，必须优先补U\-Boot/DTS/DSA/驱动

3\. **拒绝x86软路由学习**：x86无DTS、无路由专用SoC、无无线驱动，对路由器开发毫无帮助

4\. **所有操作必须知其所以然**：不要复制粘贴编译命令，每一步都要懂原理
